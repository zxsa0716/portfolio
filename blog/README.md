## 바로 쓰는 방법
각 폴더의 **`NN_슬러그.docx`** 를 워드로 열어 **본문 전체를 복사 → 티스토리 편집기에 붙여넣기**하면
제목·소제목·본문·그림·캡션이 그대로 들어갑니다. 그림이 안 옮겨지는 경우 `figures/` 이미지를 순서대로 업로드하세요.

## 파일 구성
- `NN_슬러그/post.md` — 원고 원본(수정은 여기서)
- `NN_슬러그/NN_슬러그.docx` — **발행용 Word (복붙 대상)**
- `NN_슬러그/figures/` — 삽입된 그림 원본
- `NN_슬러그/_contact.png` — 발표자료 전체 썸네일(그림 교체 시 참고)
- `_build/md2docx.py` — post.md → docx 변환기 (`python md2docx.py` 실행 시 전체 재생성)
- `_plans/` — 블로그 전수 분석 + 글감 마스터플랜

## 원고 원칙
- 정적·깔끔한 존댓말 서술체. 전문용어는 나올 때마다 풀어서 설명(비전공 독자 기준)
- 그림 캡션은 문장형: "이 그림은 ~를 보여줍니다. ~를 보시면 ~"
- 구조: 여는 글 → 문제 정의 → 데이터·방법 → 결과(그림별 해석) → 의미 → 배운 것 → 링크
- 모든 수치는 발표자료 원문에서 확인한 실제 값만 사용
- 하단에 데모·GitHub·DOI 링크 고정
