## 바로 쓰는 방법 (티스토리 마크다운 모드)

각 폴더에 파일이 3종 있습니다.

| 파일 | 용도 |
|---|---|
| **`NN_슬러그.docx`** | **발행용.** 본문이 마크다운 원문 그대로 담겨 있음 (`#`, `##`, `**굵게**`, `*기울임*`, `---`, 표, `>` 인용). 글자 서식을 일절 입히지 않아 붙여넣을 때 문법이 깨지지 않습니다. 그림은 캡션 자리에 삽입되어 있습니다. |
| `NN_슬러그_미리보기.docx` | 사람이 읽고 검토하는 용도. 서식을 적용해 조판한 판본. **붙여넣기용이 아닙니다.** |
| `그림_업로드순서.txt` | 그림이 본문에 나오는 순서와 파일명. 이미지가 붙여넣기로 옮겨지지 않을 때 이 순서대로 올리면 됩니다. |

### 발행 절차

1. 티스토리 글쓰기 → 오른쪽 위 편집기 선택에서 **`마크다운`** 을 고릅니다. (기본모드로 붙이면 `##`, `**`가 글자 그대로 보입니다.)
2. `NN_슬러그.docx`를 열어 **본문 전체를 복사**해 편집기에 붙여넣습니다.
3. 그림이 함께 올라갔는지 확인합니다. 안 올라갔다면 `그림_업로드순서.txt` 순서대로 `figures/`의 이미지를 해당 캡션 위에 끌어다 놓습니다.
4. 제목(첫 `#` 줄)은 티스토리 제목 칸으로 옮기고 본문에서는 지웁니다.
5. 카테고리는 각 원고 앞머리의 `category` 값을 참고합니다.

> 마크다운에는 밑줄 문법이 없습니다. 밑줄이 필요하면 `<u>강조</u>` 처럼 쓰면 티스토리에서 그대로 밑줄로 나옵니다.

## 그림 원칙 (중요)
발표자료 캡처보다 **아래 순서로 우선**합니다.
1. **논문 게재본 Figure** (해당 편이 논문일 때)
2. **코드 저장소의 원본 분석 그림** — 분석에서 직접 생성한 PNG. 화질·권리 모두 깔끔
3. **라이브 웹데모 실제 화면** — 배포된 서비스를 실행해 촬영
4. 발표자료 페이지 캡처 (배경·개념 설명 보조용)

## 파일 구성
- `NN_슬러그/post.md` — 원고 원본(수정은 여기서)
- `NN_슬러그/NN_슬러그.docx` — **발행용 Word (마크다운 원문, 복붙 대상)**
- `NN_슬러그/NN_슬러그_미리보기.docx` — 검토용 조판본
- `NN_슬러그/그림_업로드순서.txt` — 그림 삽입 순서
- `NN_슬러그/figures/` — 삽입 그림
- `_build/md2docx.py` — post.md → 발행용(마크다운 원문) + 미리보기 + 그림순서표를 한 번에 생성. `python md2docx.py` 실행 시 발행 대상 전체 재생성(`_pending`·`_plans` 자동 제외)
- `_plans/` — 블로그 전수 분석 + 글감 마스터플랜

## 원고 원칙
- 정적·깔끔한 존댓말 서술체. 전문용어는 나올 때마다 풀어서 설명(비전공 독자 기준)
- 그림 캡션은 문장형: "이 그림은 ~를 보여줍니다. ~를 보시면 ~"
- 구조: 여는 글 → 문제 정의 → 데이터·방법 → 결과(그림별 해석) → 의미 → 배운 것 → 링크
- 모든 수치는 원문(논문·발표자료·라이브 서비스)에서 확인한 실제 값만 사용
- 하단에 데모·GitHub·DOI 링크 고정
