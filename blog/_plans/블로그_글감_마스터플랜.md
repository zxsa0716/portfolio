## B. 공통 글 템플릿 (모든 글에 적용 — 깔끔 버전)
1. **여는 글** — 뉴스/현실 문제 1~2문장 + 이 글에서 무엇을 보일지 (감정 절제)
2. **문제 정의 / 왜 필요한가** — 숫자로 스케일 제시
3. **데이터 & 방법** — 출처·규모 표 + 단계별(1·2·3) 설명, 핵심 수식/기법만
4. **결과** — 그림별로 “이 그림이 보여주는 것” 1~3문장 해석 + 성능 수치 못박기
5. **활용 / 의미** — 정책·현장·확장성
6. **맺음말 + 링크** — 데모·GitHub·DOI·논문 링크(항상 하단 고정)

- 분량: **4,000~6,000자**(논문·대상글은 6,000~7,000)
- 이미지: **6~10장**, 각 캡션 + 본문 1~3문장 해석
- 하단 공통 푸터: `포트폴리오 https://portfolio-eight-ruddy-87.vercel.app · GitHub github.com/zxsa0716`

### ① Urban Climate(IF 6.9) 제1저자 — *최우선*
- **제목안**: “설명가능 AI는 ‘폭염이 누구에게 더 잔인한지’를 어떻게 증명했나 — IPCC AR6를 GAT에 심다”
- **카테고리**: climate / with python (신규 `research` 카테고리 신설 권장)
- **훅**: 폭염 사망은 균등하지 않다. 열 리스크를 ‘설명가능하게’ 정량화한 첫 시도.
- **구조**: 여는글(폭염 불평등) → HVI(열취약성지수)의 한계(주관 가중·블랙박스·미검증) → AR6 4요소(Hazard·Exposure·Vulnerability·Adaptive Capacity)를 GAT에 구현 → 3종 XAI(SHAP·GNNExplainer·Integrated Gradients) 교차검증 → 결과(R² 0.9681, 13,170 관측, 취약 자치구 지도) → 정책(선제 배분) → 게재 의미·링크
- **피규어 키트(8장)**:
  1. 연구 개념도(AR6 4요소→GAT) — *소스: 우수대학원생_발표.pdf 표지/개요 슬라이드*
  2. GAT 아키텍처 구조도 — *발표.pdf 방법 슬라이드*
  3. 서울 열 리스크 지도(choropleth) — *발표.pdf 결과지도*
