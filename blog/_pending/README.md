# 예비 보류 원고 (발행 준비 안 함)

아래 3편은 **아직 논문화되지 않은 연구**이므로 초안만 보관하고 실제 발행 준비는 하지 않습니다.
논문 게재 또는 공개가 확정된 뒤에 상위 폴더로 옮겨 발행 준비를 진행하세요.

| # | 글 | 상태 | 사유 |
|---|---|---|---|
| 06 | 폭염 예산의 사망 감소 효과와 최적 배분 | 초안 보관 | 학회 구두발표만, 논문화 전 |
| 07 | 기후변화가 인도차이나 산불 추세에 미친 영향 | 초안 보관 | 학회 포스터, 논문화 전 (제2저자) |
| 08 | 강원 침엽수림 회복탄력성 상실(EWS) | 초안 보관 | 학회 포스터, 논문화 전 (제2저자) |

각 폴더에는 `post.md`(원고), `figures/`(그림), `*.docx`(변환본)가 그대로 남아 있으므로
발행이 결정되면 `_build/md2docx.py` 경로만 조정해 바로 재생성할 수 있습니다.
